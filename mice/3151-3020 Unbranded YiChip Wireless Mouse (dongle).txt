Unbranded YiChip Wireless Mouse (3151:3020)

VID:PID    3151:3020
Type       Real device
Source     Dumped from device, 2026 (exact bytes)

Notes
  - Unbranded $3 wireless mouse with YiChip YC1011-S controller.
  - HID device descriptors feature an incorrect bcdHID value of 0x0200 (there is no version 2.00 of the HID specification).
  - Mouse HID report descriptor claims X & Y to be 16-bit values between -2047/+2047, but only ever reports values to -126/+126.
  - Mouse HID report descriptor also claims AC pan input, but scroll wheel doesn't have horizontal pan.
  - Even when mouse idle mode has been set (with Set Idle request) to infinite for all report IDs, still issues continuous reports while any button is pressed.

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 64 bytes
  Interface 1: class 03 (HID), subclass 01 (boot), protocol 02 (mouse), endpoint max packet 64 bytes
